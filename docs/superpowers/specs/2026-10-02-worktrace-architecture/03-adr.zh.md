## ADR-001 统一 Ant Design

现有自定义组件仅依赖 antd；移除未使用 MUI/emotion 可降低依赖维护成本。未引用的库不必然进入产物，不能承诺包体减半。评估后再改依赖并构建验证。

## ADR-002 分层单体

不拆多 crate、不造工作流；纯事件类型和运行时分发分离，必要业务直接同事务完成后通知。测试关注真实边界与故障。

## ADR-003 rusqlite + bundled

数据库只经 Rust 服务访问。同步 IO 隔离在阻塞边界；具体 DB worker 或 spawn_blocking 经试验选择。WAL/foreign_keys/busy_timeout/备份竞争需明确。其他库并非不可用，本项目暂取较小配置成本。

## ADR-004 Dockview 正式用途

**状态**：已定（2026-10-02）。固定布局先用；保留 dockview 依赖，`DockviewDemo` 不进 V0.1 发布产物。已明确需要同屏多面板时再接 dockview 并做布局持久化。

组件与演示继续保留。默认固定布局先验证 Today；若存在真实多视图并列需求再定义布局持久化与面板契约。不得因文档建议删除用户要求复制的文件。

## ADR-005 Windows 优先、平台边界

原生实现集中 platform；不预做其他 OS，不因单实现绝对禁止测试时钟/边界接口。HUD 试验不阻塞记录闭环。

## ADR-006 Rust 业务权威

React 持视图缓存和临时状态；允许按复杂度选状态库。多窗口需要收敛协议，不能保证永远同步。Tauri 为单一核心而非整个 OS 单进程。

## ADR-007 实际工时由有效区间聚合

不存 task.actual_duration，work_interval 为事实依据；缓存如有需可重建。历史修正也使缓存失效，不能仅 session finish 更新。

## ADR-008 时间单位与时区

时间戳 Unix 毫秒、时长毫秒；单调时钟测 live 时长。报表记录查询时区，Today 用用户当前时区，历史重新按选定时区分桶；计划块保留创建时区。休眠和改时规则见 02，不能假定 UTC 本身解决所有计时。

## ADR-009 HUD/Mini 轻量入口

建议独立入口，单入口懒加载可替代；比较实际启动/内存/打包路径，按当前 Vite API 实现，不能先认定加载整套主页面。

## ADR-010 事务 revision + 收敛

业务写事务和 revision 一起提交，每事务一条合并失效事件；先监听后快照、丢弃旧响应、前台轻量版本校验。tick 独立 run_id/tick_seq，不持久化每秒版本。事件丢失不回滚已提交业务。

## ADR-011 有效工作区间与恢复

V0.1 引入 work_interval，不等 V1 活动分段；数据库部分唯一索引保障运行前台占用。旧 run 含不确定区间者待确认，可信暂停仍保持 paused；只排除不确定区间，保留已确认闭合工时，不使用两分钟门槛；人工修正带版本与审计。

## ADR-012 版本与产品取舍

**状态**：已定（2026-10-02 批准）

核心记录/修正/恢复/最小周回顾与备份先交付，HUD 到 V0.1b；M09 最小策略 V0.3，完整上下文 V0.4。

## ADR-013 建议来源、输入确认与外部 Agent

保留建议/反馈/输入版本及用户采纳；输入和目的地逐次确认。取消四级文件密级与提取缓存；文件解析由外部工具承担，导入结果保持来源且不自动外发。能力短板分析保留，KPA 聚焦工作证据整理。旧保密图不再代表当前设计，当前输入边界见 07。

## 核查依据

SQLite 支持部分唯一索引；包含 NULL 的普通唯一约束不能保障根标签唯一。Rust 的单调时钟跨平台休眠行为需要明确策略。Tauri 的核心进程与 WebView 进程需区分。依据如下，不表示当前仓库已经完成相关实现。

- [SQLite partial indexes](https://www.sqlite.org/partialindex.html)
- [SQLite NULL handling](https://www.sqlite.org/nulls.html)
- [Rust Instant](https://doc.rust-lang.org/std/time/struct.Instant.html)
- [Tauri process model](https://v2.tauri.app/concept/process-model/)

当前产品边界（2026-10-03）：个人工作记录与任务管理，包含能力短板分析和 KPA 工作证据整理；文件读取、OCR、正文提取和正文搜索交给外部 Agent 与配套 skill。见 [范围与导入契约](07-scope-and-agent-import.zh.md)。
